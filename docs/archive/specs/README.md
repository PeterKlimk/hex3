# Archived specifications and experiment records

These files are historical evidence. The directory preserves their former
relative links, but “spec,” “done,” “default,” and “current” inside a file are
revision-relative and do not describe the present product automatically.

Current model status lives in the
[`../../experiment-registry.md`](../../experiment-registry.md); current
priorities live in the [`../../roadmap.md`](../../roadmap.md).

This collection includes prospective specs, completed hand-offs, falsified
hypotheses, implementation diaries and parked research. Consult the
[`../../inventory/documentation.md`](../../inventory/documentation.md) for the
file-by-file classification made before archival.
