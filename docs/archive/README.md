# Documentation archive

Files here are preserved design history, not current architecture or active
instructions. They may describe implemented, parked, falsified, superseded or
removed behavior at different revisions.

Use the canonical [`../README.md`](../README.md) and
[`../experiment-registry.md`](../experiment-registry.md) before relying on an
archived claim. Code and tests remain authoritative for current behavior.
